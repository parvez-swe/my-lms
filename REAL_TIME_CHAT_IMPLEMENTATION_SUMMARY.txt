🔄 DATA FLOW
═══════════════════════════════════════════════════════════════════════════════

NEW CONVERSATION CREATION
  1. User clicks "Chat" button on user in Sidebar
  2. Sidebar calls POST /api/chat/create-conversation
  3. API creates or fetches existing conversation
  4. Sidebar updates conversations state
  5. Sidebar calls onSelectConversation callback
  6. Page sets selectedConversation state
  7. Chat component receives as prop
  8. Chat loads messages via GET /api/chat/messages/[id]
  9. Messages display with auto-scroll

MESSAGE SENDING
  1. User types message and presses Enter
  2. Chat calls handleSendMessage()
  3. POST /api/chat/messages/[conversationId]
  4. API creates ChatMessage and adds to data
  5. API returns new message
  6. Chat adds to messages state
  7. Message renders with proper styling
  8. Auto-scroll shows latest message
